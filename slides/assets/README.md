# Manuscript illustration

`manuscript-drafts.png` is an AI-generated illustration created with the built-in image generation tool for slide 2, “Why version control?”. It depicts a fictional researcher and manuscript drafts; the plots are illustrative, not scientific evidence.

Keep this file in `assets/` beside the slide source when compiling the source bundle. The project-root build also supports `slides/assets/`.

## Generation prompt

Use case: scientific-educational. Asset type: a single editorial illustration for the left half of a clean academic presentation slide titled 'Why version control?'. Subject: a graduate researcher at a laptop, puzzled by several nearly identical manuscript drafts represented by overlapping sheets of paper with subtle typeset lines and a small scientific plot. Communicate uncertainty about which draft is the current version. Style: sophisticated minimal flat editorial illustration with subtle paper texture, crisp shapes, generous white negative space, appropriate for an IT specialist interview at a research institute. Palette: deep navy #112D42, teal #087E83, pale blue-grey, pure white background. Composition: compact centered scene, landscape 4:3, all objects fully within the frame with white margins, balanced silhouette, suitable for placement at about 115mm wide on a white slide. No legible text, no filenames, no logos, no watermarks, no title, no decorative border, no arrows, no Git branching diagrams. The filenames and question will be added as editable slide text outside the image.
